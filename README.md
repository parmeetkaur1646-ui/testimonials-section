# Task 5: Testimonials Section

## 📌 Project Overview

A **responsive and interactive Testimonials Section** built using **HTML, CSS, and JavaScript**. The project displays customer feedback in an attractive card-based layout that is easy to use and works smoothly across different screen sizes.

This project was developed as part of the **SpireX Foundation training tasks**.

## 🛠️ Technologies Used

* **HTML5** – Used to structure the testimonials section.
* **CSS3** – Used for styling, card layouts, responsiveness, animations, and visual design.
* **JavaScript** – Used to add interactivity and dynamic behavior.

* 🎨 Clean and modern user interface
